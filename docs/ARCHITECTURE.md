# بنية المشروع

المشروع مقسم إلى وحدتين:

| الوحدة | النوع | المحتوى |
|---|---|---|
| `:domain` | Kotlin/JVM خالصة | النماذج الأساسية وكل المعادلات المالية (BigDecimal). لا تعتمد على Android، فتُختبر بسرعة. |
| `:app` | تطبيق Android | قاعدة البيانات، المستودعات، الخدمات، الواجهات، الإشعارات، التقارير. |

## الطبقات (Clean Architecture + MVVM)

```
ui (Compose Screens) ──► ViewModel (StateFlow) ──► Repository ──► Room DAO / DataStore / CurrencyService
                                         │
                                         └──► domain.calc (FinanceCalculator, CurrencyConverter, TransferCalculator, DebtCalculator)
```

- **domain/calc**: إجمالي الشهر، التغير ونسبته وحالته، النسب من الإجمالي، المتوسط، الأعلى والأقل، أفضل وأسوأ شهر، التحويل بين العملات، تثبيت السعر، أثر التحويلات، الديون والمتبقي والتجاوز. قواعد التقريب موحدة في `Money`: المبالغ بدقة 2، الأسعار 6، النسب 4، و HALF_UP.
- **data/db**: Room مع 14 جدولًا وفهارس ومفاتيح أجنبية، والقاعدة مشفرة عبر SQLCipher.
- **data/repo**: `LiquidityRepository` (العناصر والأشهر والأرصدة والتحويلات وتثبيت الأسعار)، `DebtRepository` (منفصل تمامًا ولا يلمس السيولة)، `CurrencyRepository`، `SeedRepository` (بيانات أول تشغيل بدون أي مبالغ)، `AuditLogger`.
- **data/analysis/LiquidityAnalyzer**: يجمع بيانات العرض (لوحة المعلومات، الرسومات، التوزيعات، تفاصيل الشهر) باستدعاء طبقة الحسابات فقط؛ لا توجد معادلات داخل الـ Composables.
- **data/currency/CurrencyService**: مصدران مجانيان قابلان للاختيار، HTTPS فقط، مهلات اتصال، ولا يُحذف أي سعر قديم عند الفشل.
- **data/backup**: نسخ احتياطي مشفر (AES-256-GCM بمفتاح مشتق من كلمة المرور PBKDF2) مع فحص سلامة SHA-256 ومعاينة ونسخة أمان قبل الاستعادة.
- **report**: توليد 14 تقريرًا وتصديرها إلى PDF (خط Noto Naskh Arabic مضمّن) و Excel و CSV.
- **notifications**: WorkManager يومي للإشعارات المحلية فقط.
- **ui**: Navigation Compose مع شريط سفلي (أو Navigation Rail على الأجهزة اللوحية)، RTL ثابت، الوضع الفاتح والداكن، أرقام عربية أو إنجليزية، زر العين لإخفاء القيم.

## قرارات مهمة

- **الرصيد الشهري لقطة تاريخية**: يحفظ كل رصيد سعر الصرف والقيمة المقابلة. الرصيد ذو السعر المثبت لا يتغير عند تحديث الأسعار، وغير المثبت يُعاد حسابه بآخر سعر.
- **التحويل الداخلي**: يخفض المرسل ويزيد المستلم في شهر التحويل، فلا يتغير الإجمالي (إلا بالرسوم عند تفعيل خصمها). حذف التحويل يعكس أثره.
- **الحذف**: Soft Delete مع سلة محذوفات واستعادة، والحذف النهائي من السلة فقط.
- **الرسوم البيانية**: مرسومة بـ Compose Canvas بدل مكتبة خارجية لدعم RTL والرسم الدائري والضغط على الأشهر بدون اعتماديات إضافية.
